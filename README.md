Desafios de Lógica: FATEC Botucatu

Este repositório foi criado para documentar e centralizar a minha evolução prática em lógica de programação e desenvolvimento de software durante o meu primeiro semestre na FATEC (segundo semestre do ano de 2026).

Na faculdade, a nossa grade curricular foca na construção de uma base sólida de lógica utilizando o Portugol.
Como estratégia de aprendizado autônomo, estou pegando todas as atividades e algoritmos propostos em aula e transcrevendo de Portugol para Python. Ao mesmo tempo que faço a faculdade, tenho assistido a cursos do Curso em Vídeo (Guanabara), e também estou inscrito em alguns cursos da CISCO que foram ofertados pela FATEC. São eles: Introdução ao Python, Introdução à Cibersegurança e Suporte ao TI.

Até o momento, converti os seguintes algoritmos:

*   **Calculadora Real: Sistema simples de operações matemáticas. Evoluído do algoritmo original para suportar números reais (`float`) e com tratamento de erro para impedir divisões por zero.
*   **Requisitos brinquedo: um exercício  feito para ver se as condições de entrada no brinquedo são atendidas. Estudo sobre condicionais.
*   **Sistema de venda: outro exercício baseado em condicionais, se a forma de pagamento for "à vista" a tela exibe um desconto, senão, o pagamento segue normalmente.
  
Tecnologias e Ferramentas Praticadas

*   Portugol (Lógica Estruturada)
*   Python (Tipos de dados, Estruturas condicionais `if/elif/else`)
*   Git e GitHub (Versionamento e portfólio)
*   Visual Studio Code (Ambiente de desenvolvimento)
